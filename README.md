# Student Note Management System

Educational JavaScript project focused on arrays, callbacks, sorting and object manipulation.

## Technologies

- JavaScript
- HTML

## Scope

The project demonstrates:

- Finding maximum and minimum student grades
- Callback functions
- Array processing
- Sorting student records by surname
- Working with JavaScript objects
- Console-based output

## Usage

Open `index.html` in a browser and use the developer console to view the results.

## Status

Completed educational project. It is no longer actively developed and is kept as part of my JavaScript learning history.
